# sotapatti-practice-plan

A single self-contained HTML file: a personal, step-by-step practice tracker.

It walks through four phases — **foundation**, **stability**, **investigation**,
and **integration** — and lets you check off steps as you go. Progress is saved
in-browser via `localStorage`, so your place is remembered between visits in
the same browser on the same device. No server, no account — just open the file.

## Usage

Open `sotapatti-practice-plan.html` in a web browser.

This is a personal project and is unrelated to any other work.
